# 🚀 Aventuri cu numere

Fișe de matematică pentru copii de 6–8 ani, cu numere care lipsesc. Se pot rezolva direct pe ecran (cu verificare automată) sau se pot tipări pe A4.

## Ce conține

- **Racheta spre Lună** – adunări cu un termen lipsă; racheta urcă la fiecare răspuns bun.
- **La ferma bunicii** – probleme scurte cu scăderi, sub formă de povestioare.
- **Balanța magică** – egalități; balanța se îndreaptă când răspunsul e corect.
- **Piramide de numere** – fiecare cărămidă este suma celor două de sub ea.
- **Codul secret al piratului** – răspunsurile corecte dezvăluie un cuvânt ascuns.

## Funcții

- 🔄 **Fișă nouă**: generează alte numere pentru o fișă sau pentru toate.
- Nivel de dificultate: numere până la 10, 20 sau 50.
- ✅ Verificare automată și stele pentru fiecare fișă rezolvată.
- 🖨️ Tipărire pe A4 (o fișă sau toate), cu loc pentru nume și dată și căsuțe goale.
- Progresul se păstrează în browser (localStorage).

Răspunsurile sunt calculate de cod, nu introduse manual, deci sunt mereu corecte.

## Publicare pe GitHub Pages

1. Urcă `index.html` și `README.md` într-un repository.
2. **Settings → Pages → Deploy from a branch**, alege `main` și `/ (root)`.
3. Site-ul va fi la `https://<utilizator>.github.io/<repository>/`.

Totul este într-un singur fișier HTML, fără server și fără instalare.
